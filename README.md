# Maglive

This repository provides the implementation of the proposed MagLive detector, which leverages audio and magnetometer data for voice liveness detection.
The code is intended to demonstrate the detector design and usage, and to support method-level evaluation and comparison with existing approaches.
 
The script "train_feature_extractor_model.py" is included to illustrate the training procedure.
A pretrained feature extractor (feature_extractor_model.h5) is provided to facilitate testing on user-provided data. 

The script "classifier.py" demonstrates how the extracted features are used for classification and performance evaluation on compatible datasets.

More details can be found within the source code.
